Lead Radar — Preview admin

Generate and approve website previews from your phone — no terminal needed.

How this works

"Generate" builds a draft from what's already in Airtable and is safe to run again later (it only refreshes Logo URL/Primary Color/Secondary Color, never overwrites services/photos/reviews you've already added). "Validate & approve" checks for placeholder text, dead links, fake numbers, etc. — it only approves (and unlocks sending) when there are zero errors.
