How this works

"Load existing content" pulls in whatever's already saved for a slug (this also runs automatically when you reopen the page with the same token+slug still remembered) — nothing is ever lost by closing the tab. "Generate" builds a draft from what's already in Airtable and is safe to run again later. "Save content" merges whatever you fill in (ChatGPT's reply, logo, colors, photos) into the existing preview — it never overwrites fields you leave blank. "Validate & approve" checks for placeholder text, dead links, fake numbers, page-links pasted instead of direct image URLs, etc. and only approves (unlocking sending) when there are zero errors. Everything written here also shows up in the matching Airtable row.
