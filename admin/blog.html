Blog admin

Write and publish blog posts from your phone — no terminal needed, once a draft exists.

0. Start a draft (terminal, one time per post)

Blog posts start as a topic, not a blank page — run this once per post (from a computer) to pick a topic and create the draft row:

npm run blog:new -- --list
npm run blog:new -- --pick=<n>

It prints the slug to use below and a copy-paste prompt (same one this page can rebuild in step 2).

How this works

Blog posts are rendered live from Airtable at /blog/<slug> (see api/blog/[...segments].js) — there's no static file to publish, so nothing here ever touches the git repo. A post starts as a draft row created by blog/scripts/new-post.mjs (topic + category/city, no content yet). This page then builds one prompt from that topic, you paste it into ChatGPT/Claude, paste the whole reply back, and "Save draft" parses it into Title/Meta Description/H1/Body and writes it to Airtable — safe to repeat as many times as you want. Draft/in-review posts still render at their real URL so you can proofread the actual page (with an "INTERNAL REVIEW" banner and noindex), they just don't show up in the public blog listing or search until "Validate & publish" passes with zero errors.
