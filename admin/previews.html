How this works

Every fresh preview is now a real 3-page mini-site (Home, a middle page whose label depends on the business category — Services, Menu, Programs, Practice Areas — and Contact), navigable with a real nav bar. "Load existing content" pulls in whatever's already saved for a slug, broken down page by page (this also runs automatically when you reopen the page with the same token+slug still remembered) — nothing is ever lost by closing the tab. "Generate" builds a draft from what's already in Airtable and is safe to run again later. The prompt in step 2 asks ChatGPT for all 3 pages in one go — paste the whole reply back in one box. "Save content" merges whatever you fill in (ChatGPT's reply, logo, colors, photos — logo/colors/photos are shared across every page) into the existing preview — it never overwrites fields you leave blank. "Validate & approve" checks every page for placeholder text, dead links, fake numbers, page-links pasted instead of direct image URLs, etc. and only approves (unlocking sending) when there are zero errors. Everything written here also shows up in the matching Airtable row. Previews generated before this update keep working as a single page — this page falls back automatically.
